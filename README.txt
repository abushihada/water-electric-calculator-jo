# 🇯🇴 Jordan Utility Bill Calculator

A web application that calculates water and electricity 
bills based on Jordan's official government tariffs (2026).

🔗 Live Demo: https://water-elec.netlify.app

## 💡 Problem Solved
Jordanians struggle to understand complex utility bill 
tiers and government subsidies. This tool makes it 
simple, accurate, and transparent.

## ⚡ Features
- 15+ electricity subscription types
- Full water tariff tiers (residential & commercial)
- Government subsidy calculation
- Smart consumption warnings
- Fully in Arabic

## 🛠️ Built With
- HTML / CSS / JavaScript
- AI-assisted development (Antegravity)
- Deployed on Netlify

## 📊 Data Source
Official Jordan tariffs from Ministry of Water 
and Irrigation & JEPCO (2026)
